# What scripts/openapi_quality.py does not yet demand a description for. One line per
# entry, each carrying its reason after `#`; an entry with no reason fails the gate, and
# so does an entry that suppresses nothing, so this list shrinks as each app is documented
# and can never rot into a mute (CONVENTIONS 1.8).
#
# Entry forms:
#   <Schema>.<property>   a property, glob-matched (`Vocabulary*.*` is every vocabulary schema)
#   op:<operationId>      one operation, glob-matched
#   tag:<Tag>             every operation carrying that tag
#
# Everything below is an app whose documentation task has not run yet
# (docs/plans/PARALLEL_PLAN.md section 3.3, the `oas-` packages). Identity and tenants
# carry no entry: they are documented. Delete a block when its task lands.
