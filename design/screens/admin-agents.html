Agents card (/admin/agents). The page reads what bleqq watches under watch read, which every member holds, and draws every control only for agents manage. bleqq's agents are listed read-only with the five facts a bank may see and the last run's status as a pill; there is nothing to press on them, so a request that would switch one off, pause it, re-scope it or run it now has no button to come from, and the server's 403 is its guard. The bank's own agents each carry a status pill from the agent's state (On positive, Paused warning, Off information) and a version pill in brand; a run's status comes from the run (Done positive, Running notice, Stopped warning, Failed negative). Cadence is a picker inside the plan's limit, and a cadence above it renders the server's 422 in place with the old value kept. Stop run confirms once and keeps what was found. There is one monthly cap for the bank: the meter is the brand green, the figure sums our own runs, and when the cap is reached scheduled runs wait and Run now is off. The AI line is the organisation switch's state with a link to Organisation, never a second switch; when it is off our agents wait and bleqq's keep running. A new agent starts switched off and covers our operating markets first, then the watched ones. Research requests (AGT-05) are drawn by their own task and sit between the spend and our agents. Two buttons per row on a phone, the primary on the right.
