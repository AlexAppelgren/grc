How it runs

Changes this for every bank.

Agent definitions card (/console/agents). It sits in the console rail beside Agent keys under the platform admin's group, and its denied state names agent definitions manage. A definition row carries its scope as an information pill (Platform or For banks), its current version in brand, Active positive and Draft information; a version is Current positive or Retired information, from its own facts. A version is published from a folder already in the repository, with a change note, and asks for a passkey; so does retiring one, and the current version has no Retire, because a newer version replaces it. Only a Platform definition has the settings panel, whose notice says in four words that the change reaches every bank; cadence, the jurisdictions it sweeps and its monthly budget are each saved behind a passkey and audited with before and after. Platform runs show status, cost, source coverage, findings and proposals for bleqq's own agents, link to Sources and coverage, and for the confirming agent to the proposals it decided. No bank's name, count or figure appears on the card, and no prompt body does.
